# Coverage boundary

The receipt proves the committed package on the recorded runtime with Composer
metadata and advisory checks, Pint, Larastan at maximum level, the package suite
on Laravel 12 and 13 with stable and prefer-lowest dependency graphs, clean
Laravel 12 and 13 consumer migrations and synthetic imports, setup syntax,
workflow safeguards, and a final clean diff. Deprecations fail every
package-test graph.

The receipt does not prove every PHP patch, a published package, production
applications, providers, deployment, or release. Add separate evidence before
crossing those boundaries.
