# Coverage boundary

The receipt proves the committed package on the recorded runtime with locked
stable dependencies, Composer metadata and advisory checks, Pint, Larastan at
maximum level, the Laravel 13 package suite, a disposable Laravel 13
prefer-lowest graph, a clean Laravel 12 consumer install, setup syntax, workflow
safeguards, and a final clean diff.

The intentionally lowest dependency graph can emit a non-failing upstream
deprecation. Record it in review evidence; do not hide a failing deprecation.

The receipt does not prove every PHP patch, a published package, production
applications, providers, deployment, or release. Add separate evidence before
crossing those boundaries.
